# 💡 Adaptive Smart Lighting System

## 📌 Overview
A simulation-based smart street lighting system that dynamically adjusts brightness based on vehicle movement to optimize energy consumption.

---

## 🚀 Features
- Distance-based adaptive lighting
- Real-time brightness adjustment
- Energy-efficient system design
- Visualization using Streamlit dashboard

---

## 🛠 Technologies Used
- Python
- Pygame (Simulation)
- Streamlit (Dashboard)
- Threading concepts

---

## ⚙️ How It Works
- Vehicles move across a simulated road
- Streetlights detect proximity of vehicles
- Lights increase brightness when vehicles are nearby
- Lights dim when no traffic is present
- Energy consumption is optimized dynamically

---

## 📊 Results
- Achieved up to 40% reduction in energy usage
- Improved efficiency over traditional lighting systems

---

## ▶️ How to Run

### Run simulation
python simulation.py  

### Run dashboard
streamlit run dashboard.py
